# Support

## Agent Kit issues and feedback

Report installation, skill loading or execution problems, incorrect or outdated
guidance, missing rules, and feature requests through
[GitHub issues](https://github.com/AzureManagedRedis/amr-agent-kit/issues).

Include your coding assistant and version, operating system, installation method,
kit version or source commit if known, and steps to reproduce the issue. Describe
what you expected and what happened.

Use a minimal, sanitized example. Do not include credentials, customer data,
confidential code, or sensitive logs in public issues.

The Agent Kit is in public preview. GitHub issue reporting does not guarantee a
response time or a fix.

## Redis service and Azure infrastructure

Microsoft Customer Service and Support (CSS) supports underlying Redis service and
Azure infrastructure scenarios through normal Azure support channels. Agent Kit
installation, execution, and output feedback are handled through GitHub issues,
not CSS.

For service or infrastructure issues, see
[Create an Azure support request](https://learn.microsoft.com/azure/azure-portal/supportability/how-to-create-azure-support-request).

## Security vulnerabilities

Do not report security vulnerabilities in public GitHub issues. Follow the
[security reporting policy](SECURITY.md).
