Azure Managed Redis guidance for AI agents

Build better Redis applications with focused agent skills.

AMR Agent Kit packages practical guidance for Redis best practices, Redis AI patterns, and Azure Managed Redis infrastructure so coding agents can make safer, more consistent design and implementation choices.

  • Azure Managed Redis security, networking, HA, DR, persistence, and observability.

Install

Use the skills with the agent environment you already have.

Install one skill or copy the full set, depending on how much guidance your agent needs. Rebuild generated files after changing source rules.

Skills CLI npx skills add AzureManagedRedis/amr-agent-kit
GitHub Copilot or VS Code cp -r skills/redis-best-practices ~/.copilot/skills/
Claude Code cp -r skills/redis-ai-patterns ~/.claude/skills/

Example prompts

Refactor this session store to use Redis safely with expiration, retries, and graceful degradation.
